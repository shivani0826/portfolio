🚀 Jenkins + Docker CI/CD Pipeline

Developed an automated CI/CD pipeline using Jenkins and Docker for a Python Flask web application. The pipeline automatically pulls the latest code from GitHub, builds a Docker image, runs the container, and pushes the image to Docker Hub — ensuring a fully automated and repeatable deployment workflow.

🧰 Tools & Technologies Used:
  • Jenkins (Pipeline automation)
  • Docker (Containerization & image management)
  • GitHub (Source code repository)
  • Python Flask (Web Application)
  • Docker Hub (Image Repository)
⚙️ Workflow:
  1. Developer commits code to GitHub repository.
  2. Jenkins automatically triggers the pipeline build.
  3. Docker image is built using the Dockerfile.
  4. Container runs on Jenkins server and image is pushed to Docker Hub.
  5. Application becomes available on port 5000 inside Docker container.
