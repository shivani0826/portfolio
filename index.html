📝 Flask To-Do Application (Docker + AWS EC2 Deployment)

Designed and deployed a production-ready Flask To-Do Web Application, fully containerized using Docker and hosted on an AWS EC2 instance. The project demonstrates end-to-end DevOps workflow including application development, Docker image creation, Docker Hub publishing, and cloud deployment.

🧰 Tools & Technologies Used:
  • Python, Flask (Backend)
  • Docker, Docker Hub (Containerization)
  • AWS EC2 (Cloud Deployment)
  • Git & GitHub (Version Control)
  • HTML, CSS, Jinja2 (Frontend)
⚙️ Deployment Workflow:
  1. Developed Flask To-Do application with templates and routing.
  2. Created Dockerfile and containerized the application.
  3. Uploaded Docker image to Docker Hub.
  4. Launched Ubuntu EC2 instance and deployed the app using Docker run.
  5. Exposed port 5000 to make the app publicly accessible.
